# STEP Semester 3

This repository contains my STEP Semester 3 Java practice, assignments, and learning progress.

## Week 1 — Arrays and Strings

In Week 1, I learned the basics of **arrays, strings, loops, nested loops, conditional statements, and string traversal**. I practiced comparing array elements, finding duplicates, calculating accuracy, tracking character streaks, finding totals and maximum values, and categorizing words based on their length.

### Topics Learned
- Arrays and nested loops
- Strings and `charAt()`
- `split()`
- Conditional statements
- Counting and accumulation
- Finding maximum values
- String traversal

## Week 2 — String Processing

In Week 2, I focused on **String manipulation and validation**. I learned methods such as `length()`, `split()`, `trim()`, `substring()`, and `replace()`. I also practiced using `StringBuilder`, character validation, `HashMap`, frequency counting, and sorting.

### Topics Learned
- String methods
- `StringBuilder`
- `trim()` and `substring()`
- `Character.isLetter()` and `isDigit()`
- `HashMap`
- Frequency counting
- String validation

## Week 3 — Control Flow

In Week 3, I learned and practiced **control-flow statements in Java**. I worked with `if-else`, logical operators, `for` and `while` loops, `switch`, `break`, `continue`, boolean conditions, nested loops, and input validation.

### Topics Learned
- `if`, `else if`, `else`
- Logical operators
- `for` and `while` loops
- `switch-case`
- `break` and `continue`
- Nested loops
- Boolean conditions
- Input validation
